# Telangana Naatu Ruchulu

Standalone React + Vite restaurant website extracted from the Replit project.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

This project is suitable for deployment on Vercel, Netlify, or another static/frontend host.

## Notes

- `node_modules` and generated build output are intentionally excluded.
- Do not commit API keys or `.env` files.
